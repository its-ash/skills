# Career Profile Optimizer

Provide a complete, searchable LinkedIn profile and a dual‑version creative resume that showcases design skills while passing ATS filters.

## When to Use
- You need to improve LinkedIn visibility, headline, About, experience, or skill sections.
- You are a designer, writer, marketer, photographer, or other creative professional who wants a resume that looks like a portfolio piece but still parses in ATS.
- You want a checklist to keep both LinkedIn and resume consistent with your personal brand.

---

## LinkedIn Profile Optimization
### 1. Photo & Banner
- Use a professional headshot. Face occupies ~60 % of frame, neutral background, high resolution.
- Add a custom banner (1584 × 396 px) that reflects your industry or personal brand. Avoid busy patterns.

### 2. Headline (max 220 chars)
- Format: **[Role] | [Key Expertise] | [Value Proposition]**
- Include exact job‑title terms and top skills recruiters search for.
- Example: `Senior Product Manager | B2B SaaS | Driving products from concept to $10M ARR`

### 3. About / Summary (1 500‑2 000 chars)
1. **Hook** – compelling first line (appears before “see more”).
2. **Paragraph 1** – who you are and core role.
3. **Paragraph 2** – key achievements, metrics, specialties.
4. **Paragraph 3** – what you’re seeking or passionate about.
5. **Skills list** – comma‑separated, include searchable keywords.
6. **Call to action** – how to contact you.

### 4. Experience Section
- For each role list: title, company (with logo link if possible), dates, location.
- Add a 1‑2 sentence role overview.
- Provide 4‑6 bullet points with quantifiable results.
- Attach media (presentations, links, images) when relevant.

### 5. Skills
- List up to 50 skills. Order by relevance and endorsement count.
- Include technical, soft, methodology, and industry terms.
- Highlight top 3 featured skills.

### 6. Featured Section
- Add portfolio pieces, articles, presentations, or media that demonstrate your expertise.

### 7. Recommendations
- Aim for 5‑10 quality recommendations.
- Request them from managers, peers, or clients after a successful project.
- Offer to write a draft or talking points to make it easy.

### 8. Keyword Optimization
1. Extract keywords from target job descriptions and top‑performing LinkedIn profiles.
2. Place keywords in headline, About, experience bullets, and skills.
3. Use exact phrase matches; repeat naturally.

### 9. Profile Completeness Checklist
- ✅ Professional photo
- ✅ Custom headline
- ✅ Current position with description
- ✅ Two past positions
- ✅ Education
- ✅ ≥5 skills (preferably 50)
- ✅ Industry and location
- ✅ ≥50 connections
- ✅ Background banner
- ✅ Featured content
- ✅ About ≥ 1 500 chars
- ✅ Media in experience
- ✅ ≥5 recommendations

### 10. Recruiter Visibility Settings
- Turn **Open to Work** on (or recruiter‑only) and specify titles, locations, and job types.
- Set profile viewing to “Show full profile”.
- Enable “Represent in LinkedIn Services” if you offer freelance services.

### 11. Content Strategy
- Post 1‑3 times per week: industry insights, lessons learned, project highlights, or helpful resources.
- Comment on others’ posts daily to increase visibility.

## Creative Portfolio Resume Strategy
### 1. Two‑Version Approach
| Version | Use When | Design Level |
|--------|----------|--------------|
| **ATS‑Compatible** | Online applications, job boards, any system that parses resumes | Clean, single‑column, ATS‑safe fonts, minimal color (use only for name/section headers) |
| **Designed** | Networking events, direct email to hiring manager, portfolio website, in‑person interview | Full creative treatment: two‑column optional, brand colors, typography hierarchy, subtle graphics |

### 2. ATS‑Compatible Resume Guidelines
- **Font:** Use ATS‑safe fonts (Arial, Calibri, Helvetica, Times New Roman). No more than two families.
- **Layout:** Single column, simple line dividers, consistent margins.
- **Styling:** Bold/italic for emphasis only. Color only for name or section headers (avoid low‑contrast text).
- **Avoid:** Tables for layout, text boxes, images, icons, graphics, multiple columns, unusual fonts.
- **Include:** Hyperlink to online portfolio (plain URL).

### 3. Designed Resume Guidelines
- **Typography:** Choose a display font for name, a readable body font. Size hierarchy: Name > Section headers > Body.
- **Color:** 2‑3 colors max. Primary for accents, secondary for headings, high contrast for body text. Ensure print‑friendly.
- **Layout:** Two‑column optional (left for skills/education, right for experience). Maintain clear visual hierarchy and ample white space.
- **Visual Accents:** Subtle icons, dividers, or personal logo if consistent with portfolio branding.
- **File:** Export as high‑resolution PDF (≤ 1 MB). Provide a web‑HTML version for responsive viewing.

### 4. Field‑Specific Tips
- **Graphic Designers:** Emphasize typography, layout, and visual hierarchy directly in the resume.
- **UX/Product Designers:** Show information architecture; include case‑study links.
- **Marketing/Brand:** Use brand‑consistent colors, storytelling flow, and measurable results.
- **Writers/Content:** Prioritize flawless copy, strong bullet phrasing, and a voice that matches your writing style.
- **Photographers/Video:** Keep design clean; focus on a strong portfolio link and a few key project metrics.

### 5. Portfolio Integration
- Add a line at the top or footer: `Portfolio: https://yourname.com`
- For each major project bullet, include a short link: `Case Study: https://yourname.com/project`
- If possible, embed a QR code in the designed PDF for quick mobile access.

### 6. Design Execution Checklists
#### Typography
- [ ] Name is the largest element.
- [ ] 3‑4 hierarchy levels max.
- [ ] Body text ≥ 10 pt.
- [ ] Line height provides breathing room.
- [ ] No more than two font families.

#### Layout
- [ ] Clear sections with logical flow.
- [ ] Consistent margins and gutters.
- [ ] Adequate white space.
- [ ] Elements align to an invisible grid.
- [ ] Scannable in ≤ 6 seconds.

#### Color
- [ ] Palette limited to 2‑3 colors.
- [ ] Text contrast meets accessibility standards.
- [ ] Prints well in black‑and‑white.
- [ ] Colors match personal brand.

### 7. Tools
- **Design‑focused:** Adobe InDesign, Figma, Adobe Illustrator, Sketch.
- **Simpler:** Canva (template), Google Docs, Microsoft Word (use plain formatting).
- **Avoid:** PowerPoint/Keynote, heavy online builders, or any tool that embeds non‑text elements in the ATS version.

## Combined Action Checklist
- **LinkedIn**
  - [ ] Upload professional photo.
  - [ ] Add custom banner.
  - [ ] Write headline using formula.
  - [ ] Rewrite About section with hook, achievements, CTA.
  - [ ] Update each experience with metrics and media.
  - [ ] Populate 50 skills, order by relevance.
  - [ ] Add 3‑5 featured items.
  - [ ] Request 5+ recommendations.
  - [ ] Insert target keywords throughout.
  - [ ] Enable Open‑to‑Work and profile visibility.
  - [ ] Schedule weekly content posts.

- **Creative Resume**
  - [ ] Create ATS‑compatible version (single column, safe fonts).
  - [ ] Create designed version (brand colors, typography hierarchy).
  - [ ] Include portfolio URL and QR code.
  - [ ] Verify each bullet contains quantifiable results.
  - [ ] Run ATS test (e.g., Jobscan) on the ATS version.
  - [ ] Export designed version as PDF ≤ 1 MB.
  - [ ] Review typography, layout, and color checklists.
  - [ ] Save both files with clear naming (e.g., `JohnDoe_Resume_ATS.pdf`, `JohnDoe_Resume_Design.pdf`).
