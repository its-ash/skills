# Domain Name Brainstormer

Generate relevant, memorable domain names for a project and verify their registration status across multiple top‑level domains (TLDs). The skill also explains why each suggestion works and highlights premium or taken names.

## When to Use
- Starting a new startup, product, or service
- Building a personal brand, portfolio, or side project
- Rebranding an existing offering
- Need alternatives after a preferred name is unavailable
- Want to explore industry‑specific or multilingual options

## Workflow
1. **Describe the project** – include purpose, target audience, key features, and any preferred keywords.
2. **State preferences** – length, desired TLDs, language, or branding constraints.
3. **Ask for suggestions** – the skill returns a list of domain names with availability status.
4. **Review the list** – note the top picks, premium/taken names, and the rationale provided.
5. **Select and register** – act quickly to secure the chosen domain(s).

## Naming Rules
- **Length**: Aim for ≤15 characters (including extension).
- **Memorability**: Simple, easy to recall, and spell.
- **Pronounceability**: Should sound natural when spoken.
- **Descriptiveness**: Hint at the product or service.
- **Brandability**: Unique enough to stand out; avoid generic terms.
- **No hyphens or numbers**: Reduce verbal complexity and typo risk.
- **Avoid trademark conflicts**: Verify that the name does not infringe existing marks.

## TLD Guide
| TLD | Typical Use | Notes |
|-----|------------|-------|
| .com | General business, universal trust | Most recognized; often premium price |
| .io | Tech startups, developer tools |
| .dev | Developer‑focused products, secure by default |
| .ai | AI/ML products |
| .app | Mobile or web applications; requires HTTPS |
| .co | Short alternative to .com |
| .xyz | Creative projects, modern branding |
| .design | Design agencies, portfolios |
| .tech | Technology companies |
| .eco | Sustainable or environmental brands |
| .fashion | Fashion industry |

## Advanced Features
- **Similarity Search** – Provide a base word and request variations across selected TLDs.
- **Industry Patterns** – Request common naming patterns in a sector, then get available equivalents.
- **Multilingual Brainstorming** – Generate names in multiple languages and check each for availability.

## Example Workflows
### Startup Launch
- Describe the startup idea.
- Receive 10‑15 domain suggestions across preferred TLDs.
- Review availability, note premium prices.
- Choose top 3 and register immediately.

### Personal Brand
- Provide name and profession.

- Verify social‑media handle availability.
- Register the chosen domain(s) and secure matching handles.

- Receive creative, brandable names.
- Perform trademark check (outside this skill).
- Verify domain and social availability.
- Test top names with a sample audience.

## Checklist
- [ ] Define project purpose, audience, and key keywords.
- [ ] State any TLD preferences or language constraints.
- [ ] Review each suggestion for length, memorability, and brandability.
- [ ] Confirm availability status (available, taken, premium).
- [ ] Perform a quick trademark search.
- [ ] Check matching social‑media handles.
- [ ] Register the chosen domain(s) promptly.

## Tips for Success
- Act quickly; good domains are taken fast.
- Register multiple extensions (.com, .io, .dev) to protect the brand.
- Say the name out loud to test pronunciation.
- Avoid numbers and hyphens.
- Verify trademark clearance before public use.
- Consider long‑term relevance; will the name still fit in 5‑10 years?

## Pricing Context
- Standard domains (e.g., .com, .io): **$10‑$15 / year**.
- Premium TLDs (e.g., .ai, .dev): **$30‑$50 / year**.
- Premium or already‑taken domains: market price ranging from **hundreds to thousands of dollars**.
