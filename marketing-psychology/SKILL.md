# Marketing Psychology & Mental Models

**Purpose** – Apply proven psychological principles and mental models to marketing decisions. Use this guide to diagnose buyer behavior, craft persuasive messages, set prices, and design growth systems ethically.

## When to Use
- You need to explain *why* customers buy or abandon.
- You are designing copy, offers, pricing, or user flows.
- You want to prioritize marketing activities based on impact.
- You are troubleshooting low conversion, high churn, or stagnant growth.

## Core Workflow
1. **Define the problem** – e.g., low sign‑ups, price resistance, churn.
2. **Select relevant mental models** – scan the sections below for models that match the symptom.
3. **Explain the psychology** – write a short sentence describing the underlying bias or principle.
4. **Map to a concrete marketing action** – list a specific tactic that leverages the model.
5. **Validate ethically** – test the tactic with A/B experiments or user interviews.
6. **Iterate** – measure results, refine the model selection, and repeat.

## Foundational Decision‑Making Models
| Model | How to Apply in Marketing |
|---|---|
| **First Principles** | Ask *why* you are doing each activity. Break the problem to its base truth before copying competitors. |
| **Jobs to Be Done** | Identify the outcome the customer hires your product for. Frame messaging around the job, not features. |
| **Inversion** | List everything that would cause the campaign to fail. Remove each failure point before launch. |
| **Pareto (80/20)** | Find the 20 % of channels, content, or audiences that generate 80 % of results. Focus resources there. |
| **Theory of Constraints** | Locate the single bottleneck that limits overall performance (traffic, conversion, retention) and fix it first. |
| **Second‑Order Thinking** | Anticipate downstream effects of a tactic (e.g., flash sales may train customers to wait for discounts). |
| **Probabilistic Thinking** | Estimate the likelihood of outcomes. Allocate budget across multiple experiments instead of betting on one. |
| **Barbell Strategy** | Put ~80 % of budget in proven channels, ~20 % in high‑risk high‑reward experiments. |

## Buyer‑Behavior Models & Tactics
| Model | Psychological Insight | Marketing Tactic |
|---|---|---|
| **Mere Exposure** | Familiarity increases liking. |
|  | • Show the brand consistently across channels. |
| **Availability Heuristic** | People judge likelihood by vivid examples. |
|  | • Use recent case studies or testimonials. |
| **Confirmation Bias** | Audiences favor information that matches existing beliefs. |
|  | • Align messaging with the prospect’s current worldview. |
| **Mimetic Desire** | Desire spreads socially. |
|  | • Highlight influencers or peers using the product. |
| **Endowment Effect** | Ownership raises perceived value. |
|  | • Offer free trials, samples, or sandbox access. |
| **IKEA Effect** | Effort increases attachment. |
|  | • Let users customize or assemble the product. |
| **Zero‑Price Effect** | Free is perceived as dramatically better than cheap. |
|  | • Provide a free tier, free shipping, or a free bonus. |
| **Hyperbolic Discounting** | Preference for immediate rewards. |
|  | • Emphasize benefits that happen today. |
| **Status‑Quo Bias** | People resist change. |
|  | • Reduce migration friction (one‑click import, data migration). |
| **Default Effect** | Pre‑selected options are chosen more often. |
|  | • Set the preferred plan as the default (opt‑out). |
| **Paradox of Choice** | Too many options cause paralysis. |
|  | • Limit choices to 3–4 clear options; highlight a “best for most.” |
| **Goal‑Gradient** | Effort rises as goal nears. |
|  | • Show progress bars or “you’re 80 % there.” |
| **Peak‑End Rule** | Experience judged by best moment and ending. |
|  | • Add a memorable surprise at checkout; craft a strong thank‑you page. |
| **Zeigarnik Effect** | Unfinished tasks stay on mind. |
|  | • Use incomplete forms or “you left something behind” reminders. |
| **Pratfall Effect** | Small flaws increase likability. |
|  | • Admit a minor limitation and follow with a strength. |
| **Curse of Knowledge** | Experts forget what novices don’t know. |
|  | • Test copy with people unfamiliar with the industry. |
| **Mental Accounting** | Money is categorized mentally. |
|  | • Present price as “$1 per day” instead of “$30 per month.” |
| **Regret Aversion** | Fear of future regret blocks action. |
|  | • Offer money‑back guarantees or risk‑free trials. |
| **Bandwagon / Social Proof** | People follow the crowd. |
|  | • Show user counts, testimonials, or “trending” badges. |

## Persuasion & Influence Techniques
| Technique | Core Principle | Example Action |
|---|---|---|
| **Reciprocity** | Obligation to return favors. |
|  | • Give a free ebook before asking for an email. |
| **Commitment & Consistency** | Small initial commitments lead to larger ones. |
|  | • Ask for a quick survey answer, then propose a trial. |
| **Authority** | Trust in experts. |
|  | • Display certifications, expert endorsements, or “as seen in” logos. |
| **Liking / Similarity** | People say yes to likable, similar others. |
|  | • Use relatable spokespersons and community language. |
| **Unity** | Shared identity drives influence. |
|  | • Position the brand as part of the customer’s tribe (“for creators”). |
| **Scarcity / Urgency** | Limited availability raises value. |
|  | • Show “Only 5 seats left” or a countdown timer (only if true). |
| **Foot‑in‑the‑Door** | Start with a tiny request, then larger. |
|  | • Free trial → paid plan → annual contract. |
| **Door‑in‑the‑Face** | Large request first, then smaller makes the second seem reasonable. |
|  | • Show enterprise pricing, then present the starter plan. |
| **Loss Aversion** | Loss feels twice as painful as gain. |
|  | • Phrase as “Don’t miss out on $200 savings.” |
| **Anchoring** | First number sets reference point. |
|  | • Display original price before discount. |
| **Decoy** | An inferior option makes another look better. |
|  | • Add a low‑value third tier to highlight the middle tier. |
| **Framing** | Presentation changes perception. |
|  | • Use “90 % success” instead of “10 % failure.” |
| **Contrast** | Comparison changes judgment. |
|  | • Show “before” and “after” results side‑by‑side. |

## Pricing Psychology
| Model | Insight | Practical Use |
|---|---|---|
| **Charm Pricing** (left‑digit) | $99 feels cheaper than $100. |
|  | Use .99 or .95 endings for value‑oriented items. |
| **Rounded‑Price (Fluency)** | Round numbers feel premium. |
|  | Use whole numbers for high‑end products. |
| **Rule of 100** | Discount perception flips at $100. |
|  | < $100 → use % off; > $100 → use $ off. |
| **Good‑Better‑Best** | Relative pricing steers choice. |
|  | Offer three tiers; position the target tier as the middle. |
| **Mental Accounting (Pricing)** | Framing changes perceived cost. |
|  | Show “$1 per day” instead of “$30 per month.” |

## Design & Delivery Models
| Model | Key Takeaway | Action |
|---|---|---|
| **Hick’s Law** | More choices = slower decisions. |
|  | Limit options; use a single CTA. |
| **AIDA Funnel** | Move prospect through Attention → Interest → Desire → Action. |
|  | Structure landing pages to hit each stage sequentially. |
| **Rule of 7** | Roughly seven touches needed to convert. |
|  | Build multi‑touch sequences (ads, email, retargeting). |
| **Nudge / Choice Architecture** | Small presentation tweaks shift behavior. |
|  | Pre‑select the preferred plan, place the best option first. |
| **BJ Fogg Behavior Model** | Behavior = Motivation × Ability × Prompt. |
|  | Ensure high motivation, low friction, and clear prompts. |
| **EAST Framework** | Make actions Easy, Attractive, Social, Timely. |
|  | Reduce form fields, add social proof, send at optimal time. |
| **COM‑B** | Capability, Opportunity, Motivation needed. |
|  | Verify users can act, have the path, and want to act. |
| **Activation Energy** | Initial effort blocks action. |
|  | Offer one‑click sign‑up or pre‑filled forms. |
| **North Star Metric** | One metric that captures core value. |
|  | Define and align all activities to that metric. |
| **Cobra Effect** | Bad incentives backfire. |
|  | Test referral or reward programs for unintended abuse. |

## Growth & Scaling Models
| Model | What It Describes | Marketing Implication |
|---|---|---|
| **Feedback Loops** | Output becomes input, creating cycles. |
|  | Build virtuous loops: users → content → SEO → more users. |
| **Compounding** | Small, consistent gains add up. |
|  | Publish regularly; benefits compound over months. |
| **Network Effects** | Value rises with user count. |
|  | Encourage user‑generated content or referrals. |
| **Flywheel** | Momentum builds with repeated effort. |
|  | Connect content, traffic, leads, customers, case studies in a loop. |
| **Switching Costs** | Barriers to leaving you. |
|  | Offer integrations, data export, team onboarding tools. |
| **Exploration vs. Exploitation** | Balance new experiments with proven tactics. |
|  | Allocate a fixed % of budget to tests each quarter. |
| **Critical Mass / Tipping Point** | Threshold after which growth self‑sustains. |
|  | Focus on a niche segment until you dominate it, then expand. |
| **Survivorship Bias** | Ignoring failures skews learning. |
|  | Study failed campaigns to avoid repeating mistakes. |

## Common Pitfalls & How to Avoid Them
- **Over‑complicating** – Apply Occam’s Razor; test the simplest explanation first.
- **Relying on a single bias** – Combine models (e.g., scarcity + social proof) for stronger effect.
- **Using false scarcity** – Misleading urgency damages trust and violates ethics.
- **Ignoring the bottleneck** – Optimizing downstream steps before fixing the top‑of‑funnel constraint wastes resources.
- **Neglecting second‑order effects** – Anticipate long‑term behavioral changes (e.g., discount fatigue).
- **Assuming universal applicability** – Test each tactic with your specific audience; cultural differences matter.

## Quick Checklist for a New Campaign
- [ ] Define the specific behavior you want (sign‑up, purchase, share).
- [ ] Identify the dominant buyer bias (e.g., scarcity, loss aversion, social proof).
- [ ] Choose 1–2 mental models that explain the bias.
- [ ] Draft a message or design element that leverages the model.
- [ ] Ensure the tactic is ethically truthful and testable.
- [ ] Set up an A/B test with a clear success metric.
- [ ] Run the test for a statistically valid period.
- [ ] Analyze results; confirm the model’s impact.
- [ ] Iterate: keep what works, discard what doesn’t, and document learnings.

## Questions to Clarify the Situation
1. What exact action are you trying to drive?
2. Where does the prospect currently drop off in the funnel?
3. What beliefs or expectations does the audience hold before seeing your message?
4. Which channels are you using, and what are their current performance metrics?
5. Have you run any experiments on this problem before? What were the outcomes?
