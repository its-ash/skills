# Paid Ads

Help marketers design, launch, and improve paid‑media campaigns. Includes platform selection, audience targeting, ad‑copy formulas, creative guidelines, budget allocation, optimization tactics, reporting, and a competitive‑ads research workflow.

## When to Use
- You need a full campaign plan for Google Ads, Meta (Facebook/Instagram), LinkedIn, X, TikTok, or similar platforms.
- You have a specific objective (awareness, traffic, leads, sales, app installs) and need targeting, copy, and creative guidance.
- You want to test, scale, or troubleshoot existing campaigns.
- You want to research competitors' ads for messaging and creative inspiration.

---

## 1. Gather Core Context
Ask the client for:
1. **Goal** – objective, target CPA/ROAS, budget, timeline, any compliance or brand constraints.
2. **Product / Offer** – description, landing‑page URL, unique selling points, promotions, urgency.
3. **Audience** – ideal customer profile, pain points, existing data for look‑alikes.
4. **Current State** – prior campaigns, pixel/conversion data, funnel conversion rates, existing assets.

---

## 2. Platform Selection Guide
| Platform | Best For | Typical Campaign Types |
|----------|----------|------------------------|
| **Google Search** | High‑intent intent, bottom‑of‑funnel conversions | Keyword‑targeted text ads, Performance Max, RLSA |
| **Google Display / YouTube** | Brand awareness, visual storytelling | Display banners, video ads, Discovery, Gmail ads |
| **Meta (Facebook/Instagram)** | Demand generation, visual products, broad audience | Advantage+ Shopping, Lead Gen, Conversions, Traffic, Engagement |
| **LinkedIn** | B2B, decision‑maker targeting, high‑value offers | Sponsored Content, Message Ads, Lead Gen Forms, Document Ads |
| **X (Twitter)** | Real‑time relevance, tech‑savvy audience | Promoted Tweets, Video, Carousel |
| **TikTok** | Younger demographics, viral short‑form video | In‑feed video ads, Branded Hashtag Challenges |

Choose the platform that matches the objective and audience. You can run multiple platforms simultaneously but keep budgets and metrics separate for clear analysis.

## 3. Campaign Structure & Naming
### Account Hierarchy
```
Account
├─ Campaign: [Objective] – [Audience] – [Offer]
│   ├─ Ad Set / Group: [Targeting variation]
│   │   ├─ Ad 1: [Creative A]
│   │   ├─ Ad 2: [Creative B]
│   │   └─ Ad 3: [Creative C]
│   └─ Ad Set 2 …
└─ Campaign 2 …
```
### Naming Convention
```
[Platform]_[Objective]_[Audience]_[Offer]_[YYYYMM]
# Example: META_Conv_Lookalike_Trial_202410
```
Consistent names make reporting and scaling easier.

## 4. Budget Allocation Framework
| Phase | Duration | Allocation |
|-------|----------|------------|
| **Testing** | First 2‑4 weeks | 70 % to proven safe sets, 30 % to new audiences/creative |
| **Scaling** | After statistical significance (≈100 conversions per variant) | Shift 80‑90 % to winning combos; increase budgets in 20‑30 % increments; wait 3‑5 days between raises |

## 5. Ad‑Copy Frameworks
### Primary Text Formulas
- **Problem‑Agitate‑Solve (PAS)**
  ```
  [Problem] ? [Agitate] → [Solution] [CTA]
  ```
- **Before‑After‑Bridge (BAB)**
  ```
  Before: …
  After: …
  Bridge: …
  ```
- **Social‑Proof Lead**
  ```
  "[Stat]" — [Name, Title] [Product] [CTA]
  ```
### Headline Formulas
- Search: "[Keyword] + [Benefit]" or "[Question]?"
- Social: Hook with outcome, curiosity, contrarian, or specificity.
### CTA Types
- **Soft** – Learn More, Watch Demo, Get Guide.
- **Hard** – Start Free Trial, Book Demo, Buy Now.
- **Urgent** – Limited Time 30 % Off, Offer Ends [Date] (use only when genuine).

## 6. Audience Targeting Strategies
### Google Ads
- **Search** – Exact, phrase, broad match keywords; optional audience layering (observation mode); RLSA.
- **Display/YouTube** – Custom intent, in‑market, affinity, Customer Match, Similar audiences.
### Meta
- **Core** – Combine interests with AND logic; start broad, let algorithm optimize.
- **Custom** – Website visitors, engagement, app activity, customer lists.
- **Lookalike** – Source best‑value customers; start at 1 % similarity, expand to 1‑3 %.
### LinkedIn
- **Job‑based** – Specific titles, functions, seniority, skills.
- **Company‑based** – Size, industry, growth rate, ABM list.
- Combine job + company for precise B2B reach.
### General Tips
- Exclude existing customers (unless upselling).
- Use frequency caps to avoid fatigue.
- Keep audience size large enough to exit learning phase (≥ 1 % of platform population).

## 7. Creative Best Practices
### Image Ads
- Show product UI, before/after, or real people.
- Use bold, legible text (< 20 % of image area).
- Avoid generic stock photos and clutter.
### Video Ads
- **15‑30 s**: Hook (0‑3 s) → Problem (3‑8 s) → Solution (8‑20 s) → CTA (20‑30 s).
- **60 s+**: Add social proof and brief “how it works” segment.
- Always add captions; use vertical for Stories/Reels, square for feed.
### Testing Hierarchy
1. Concept/angle
2. Hook/headline
3. Visual style
4. Body copy
5. CTA
Test one variable at a time. Aim for ≥ 100 conversions per variant for statistical confidence.

---

## 8. Optimization Levers
| Symptom | Quick Checks | Action Steps |
|---------|--------------|--------------|
| **High CPA** | Landing‑page conversion? | Improve page speed, copy, form length; tighten audience; test new creative; raise relevance score; adjust bid caps |
| **Low CTR** | Creative relevance? | Refresh hook, try new visual; refine targeting; rotate ad copy; add stronger offer |
| **High CPM** | Audience too narrow or competition high? | Expand targeting, test alternative placements, improve relevance score, lower bid aggressiveness |

### Bid Strategies
- **Manual / Cost Caps** – Use early when data is limited.
- **Automated (Target CPA/ROAS, Max Conversions)** – Switch after ≥ 50 conversions/month.
Progress from manual → automated as data accrues.

## 9. Retargeting Funnel
| Funnel Stage | Audience | Message | Frequency |
|--------------|----------|---------|-----------|
| **Top** (awareness) | Blog/video viewers | Educational content, social proof | 1‑2 ×/week |
| **Middle** (consideration) | Pricing/feature page visitors | Case studies, demos, comparisons | 3‑5 ×/week |
| **Bottom** (decision) | Cart abandoners, trial users | Urgency, objection handling, discount | Higher (up to daily) |

**Exclusions** – Existing customers, recent converters (7‑14 days), bounce‑visitors (< 10 s), irrelevant site sections.

## 10. Reporting & Analysis Checklist
### Weekly
- Spend vs. budget pacing
- CPA/ROAS vs. targets
- Top‑ and bottom‑performing ads
- Audience performance breakdown
- Frequency & ad‑fatigue signals
- Landing‑page conversion rate
- Disapproved ads or policy alerts
### Monthly
- Channel‑level ROI
- Creative performance trends
- Audience insights & new segments
- Budget reallocation recommendations
- Test results summary & next‑test plan
- Competitive landscape notes

**Attribution** – Use UTM parameters; compare platform data with GA4 or other analytics; consider blended CAC rather than platform‑only CPA.

## 11. Platform‑Specific Setup Checklists
### Google Ads
- Install & verify conversion tracking (global site tag & GA4 link).
- Build audience lists: remarketing, customer match, in‑market.
- Create negative keyword lists.
- Enable ad extensions (sitelinks, callouts, snippets).
- Run a brand‑defense campaign.
- Set location, language, ad schedule.
### Meta
- Install Pixel & verify events.
- Set up Conversions API.
- Create custom & lookalike audiences.
- Connect product catalog (e‑commerce).
- Verify domain & configure aggregated event measurement.
- Prepare assets in required sizes.
### LinkedIn
- Install Insight Tag.
- Configure conversion tracking.
- Build matched audiences (company list, website visitors).
- Prepare lead‑gen form templates.
- Validate audience size (avoid too narrow).
- Set realistic CPC budget (US $8‑15+ typical).

## 12. Common Mistakes to Avoid
- **No tracking** – launch without pixel or conversion tags.
- **Over‑fragmented structure** – too many campaigns/ad sets dilute budget.
- **Insufficient learning time** – change bids or creatives before 50‑100 conversions.
- **Wrong optimization goal** – optimize for clicks when you need conversions.
- **Audience extremes** – too narrow (no learning) or too broad (wasted spend).
- **Creative fatigue** – run a single ad for weeks; refresh every 1‑2 weeks.
- **Landing‑page mismatch** – ad promises differ from post‑click experience.
- **Ignoring mobile** – not testing mobile‑first creatives or page speed.
- **Policy violations** – avoid excessive text on images (Meta) and prohibited claims.

## 13. Competitive Ads Research Workflow
1. **Identify Competitors** – list 3‑5 direct rivals.
2. **Extract Ads** – use platform libraries (Facebook Ad Library, LinkedIn Ads, TikTok Creative Center) to pull active ads.
3. **Capture Screenshots** – save each ad image/video for visual reference.
4. **Catalog Data** – create a spreadsheet with columns: Platform, Ad ID, Format, Headline, Primary Text, CTA, Target Audience (if known), Date.
5. **Analyze Messaging** – group ads by theme (problem, use‑case, value prop). Note recurring pain points, tone, and length.
6. **Identify Creative Patterns** – before/after split, UI showcase, social proof, color scheme, video length.
7. **Extract Copy Formulas** – record headline structures, CTA phrasing, character counts.
8. **Derive Insights** – answer: Which problems appear most? Which formats get higher engagement? Where are gaps you can own?
9. **Apply to Your Campaign** – adapt successful formulas to your own product, ensuring originality and compliance.
10. **Document & Iterate** – store analysis in a shared folder; repeat quarterly to track market shifts.

**Legal/Ethical Note** – Use competitor ads only for research and inspiration. Do not copy copy or visual assets verbatim.

## 14. End‑to‑End Checklist
- [ ] Define objective, CPA/ROAS, budget.
- [ ] Gather product details and landing‑page URL.
- [ ] Build audience personas and collect first‑party data.
- [ ] Choose platform(s) based on objective.
- [ ] Set up conversion tracking and UTM parameters.
- [ ] Create campaign hierarchy with naming convention.
- [ ] Allocate test budget (70/30 split).
- [ ] Write primary text using PAS/BAB/Proof formulas.
- [ ] Draft headlines per platform guidelines.
- [ ] Produce 3‑4 creative variations (image/video).
- [ ] Launch with manual bids or cost caps.
- [ ] Monitor daily: spend, CPA, CTR, frequency.
- [ ] After 100 conversions per variant, analyze and pause losers.
- [ ] Scale winning combos, increase budget 20‑30 % increments.
- [ ] Set up retargeting funnels (top, middle, bottom).
- [ ] Run weekly review checklist; adjust bids, audiences, creative.
- [ ] Conduct competitive‑ads extraction quarterly; integrate new messaging angles.
- [ ] Document learnings and plan next test cycle.
