# Skill router

Machine-readable index of every skill in this repo. An agent should scan the
**Triggers** column, load the matching `SKILL.md`, then follow that file's
**Related skills** links when the task is broader than one skill.

Total skills: **26**

## How auto-invocation works

1. A task arrives.
2. Match the task's nouns and verbs against **Triggers** below.
3. Load every matching `<skill>/SKILL.md` (more than one is normal).
4. Follow each loaded skill's **Related skills** list one hop for adjacent work.
5. Load `<skill>/references/*.md` only when the specific sub-topic comes up.
