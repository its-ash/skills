# Skill Router

Authoritative routing index for all 45 skills and their `references/` sub-skills. Shared across Copilot (`~/.copilot/skills/`), Claude Code (`~/.claude/skills/`), Gemini CLI (`~/.gemini/skills/`), and Zed (`~/.agents/skills/`).

## Auto-Invocation Protocol (mandatory, silent)

1. **Match on every request:** Scan task nouns, verbs, file extensions, frameworks, CLI tools, and symptoms against **Triggers** below.
2. **Load automatically:** Read every matching `<skill>/SKILL.md` without waiting to be asked (loading 2-4 skills together is normal, e.g. `design` + `frontend-development` + `typescript` + `clean-code`).
3. **Follow one hop:** Read any applicable skill listed in the loaded skill's `## Related skills` section.
4. **Load sub-skills on demand:** Read `<skill>/references/<sub-skill>.md` only when the task matches that sub-skill.
5. **Stay silent:** Never list or announce loaded skills unless the user asks. On conflict, global instructions (`copilot.instructions.md` / `CLAUDE.md` / `GEMINI.md` / `AGENTS.md`) win.
