Install

One command clones the repo and links every skill, agent, and instruction file into both GitHub Copilot (~/.copilot) and Claude Code (~/.claude).

# git clone && link skills + instructions
git clone https://github.com/its-ash/skills.git && cd skills && ./setup.sh

Already cloned? Run ./setup.sh to install, ./setup.sh --status to check, or ./setup.sh --unlink to remove.
