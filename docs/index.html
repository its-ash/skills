Install

One command clones the repo and links every skill, agent, command, and instruction file into GitHub Copilot (~/.copilot), Claude Code (~/.claude), Gemini CLI (~/.gemini), and Zed (~/.config/zed).

# clone && link across Copilot, Claude Code, Gemini CLI, and Zed
git clone https://github.com/its-ash/skills.git && cd skills && ./setup.sh

Flags: ./setup.sh --clean (replace all), --overwrite (keep others), --status (inspect links), --unlink (remove).
